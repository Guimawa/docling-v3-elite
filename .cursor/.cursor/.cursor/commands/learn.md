# Learn

Enregistre une leçon apprise (correction utilisateur) dans LEARNING-LOG.md.

## Workflow

1. L'utilisateur a corrigé quelque chose
2. Exécuter /learn avec le résumé de la correction
3. Ajouter une entrée dans docs/LEARNING-LOG.md (ou LEARNING-LOG.md)
4. Format : Date, Contexte, Erreur, Correction, Leçon

## Exemple

`/learn Ne pas utiliser OFFSET pour la pagination, utiliser cursor-based comme dans le projet`

→ Ajoute une entrée dans LEARNING-LOG avec cette leçon.
