# Dev — Feature Developer

Implémente une tâche selon spec/design. **Applicable à tout projet.**

## Workflow

1. Lire spec.md et design.md du dossier feature
2. Implémenter une tâche à la fois
3. Tenir implementation_notes.md si présent
4. **Exécuter** lint + tests du projet avant de terminer

## Adapter au projet

Identifier les commandes de validation (npm run lint, pytest, make validate-all, etc.) et les exécuter.
