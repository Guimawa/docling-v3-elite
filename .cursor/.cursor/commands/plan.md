# Plan — System Architect

Décompose l'objectif en tâches avec spec et design. **Applicable à tout projet.**

## Workflow

1. Créer `docs/planning/{feature}/` (ou structure équivalente du projet)
2. README.md — objectif, critères de succès
3. spec.md — spécification fonctionnelle
4. design.md — design technique (API, schéma, composants)
5. Produire checklist avec @dev, @test, @review, @docs

## Adapter au projet

Consulter README, structure docs/, .cursor/rules pour les conventions.
