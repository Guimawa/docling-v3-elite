# TECH STACK — DOCLING V3 (ELITE)

## Frontend Mobile
- **Framework** : Expo (React Native).
- **Navigation** : Expo Router.
- **State Management** : Zustand + TanStack Query.
- **Camera** : Expo-Camera (Next).
- **Styling** : Vanilla CSS / NativeWind (si demandé).

## Frontend Web (Aurora)
- **Framework** : Vite + React.
- **Animations** : Framer Motion + Anime.js.
- **Visuals** : D3.js (pour les graphiques Atlas), Recharts (pour les analytics), Leaflet (pour la cartographie Atlas).

## Backend (Edge)
- **Framework** : Hono.
- **Runtime** : Cloudflare Workers.
- **Auth** : Better Auth.
- **AI SDK** : Vercel AI SDK ou Gemini API direct.

## Infrastructure
- **Base de Données** : Supabase.
- **Stockage** : Cloudflare R2.
- **Observabilité** : Sentry / LangSmith (IA).
