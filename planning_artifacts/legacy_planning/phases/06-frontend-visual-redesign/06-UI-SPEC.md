## Spacing Scale

Declared values (multiples de 4 uniquement — 8-point base grid):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge padding horizontal |
| sm | 8px | Compact element spacing, gap entre icône et label |
| md | 16px | Padding cards, gap entre éléments de liste |
| lg | 24px | Padding pages (p-6), section gaps |
| xl | 32px | Gaps entre sections majeures |
| 2xl | 48px | Breaks entre blocs de contenu distincts |
| 3xl | 64px | Page-level spacing (haut de page avant premier bloc) |

Exceptions:
- Touch targets navbar mobile: 44px minimum (hauteur tap zone) — contrainte PWA
- Safe area iOS bottom: `env(safe-area-inset-bottom)` appliqué via `.pb-safe` (classe globale existante)
- Padding page horizontal mobile: 20px (p-5) — valeur actuelle à conserver pour densité

## Color

### Palette Dark (Option C — corail fort)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#111827` (gray-900) | Background principal de toutes les pages (`bg-[#111827]`) |
| Secondary (30%) | `#1F2937` (gray-800) | Cards, panels, navbar, modals, zones de saisie |
| Accent (10%) | `#E05C3A` (corail brand) | Voir liste ci-dessous — JAMAIS sur fond ou texte courant |
| Destructive | `#DC2626` (error existant) | Actions destructives uniquement (supprimer, annuler) |

Accent `#E05C3A` réservé UNIQUEMENT pour:
- Bouton CTA primaire (fond solide + texte blanc)
- État actif de la navbar (icône + label + indicateur underline)
- Focus ring des inputs (`ring-[#E05C3A]/20`)
- Badges de statut "Nouveau" ou compteur actif
- Icône/illustration de la page courante dans l'en-tête de page (accent iconique unique)

Couleurs sémantiques (inchangées):
- Success: `#2E9E60` — produits validés, OK, sync réussi
- Warning: `#F5961D` — confidence low, en attente, hors ligne
- Error: `#DC2626` — échec, champ invalide
- Info: `#4A7CF7` — tooltip, nouveau, information neutre

Texte:
- Primaire: `#F9FAFB` (gray-50) — titres, labels importants
- Secondaire: `#9CA3AF` (gray-400) — texte courant, descriptions
- Désactivé: `#6B7280` (gray-500) — placeholders, disabled states

Borders:
- Standard: `#374151` (gray-700)
- Subtile: `#1F2937` (gray-800) — séparations internes de card

Gradients: INTERDITS dans cette phase (user_decisions Q4: pas de gradients flashy)

## Per-Page Layout Contract

```

│  Page header (px-5 pt-6 pb-4)            │
│  Icône accent 24px + Titre (Sora 20px)   │
│  Sous-titre optionnel (DM Sans 14px gray-400) │
├──────────────────────────────────────────┤
│  Contenu (px-5 pb-24)                    │
│  (pb-24 = navbar 64px + safe area)       │
│  ...                                     │
├──────────────────────────────────────────┤

```

Règle: `min-h-screen bg-[#111827]` sur le wrapper racine de chaque page.

- PDF preview: `bg-gray-900 rounded-xl` avec border gray-700
- CTA principal: "Sauvegarder dans le catalogue" — bouton primaire corail full-width mobile

### CataloguePage

- Filtres (Search + Select): inputs fond `bg-gray-800 border border-gray-700`, focus ring corail

### HistoryPage

## Animation Contract

Framer Motion déjà en place. Style cible: Linear (discret, fonctionnel, pas de bounce).

| Interaction | Animation | Duration |
|-------------|-----------|----------|
| Entrée de page | `fadeIn` + `y: 10 → 0` | 250ms easeOut |
| Entrée de card/liste | `staggerContainer` enfants `slideUp` | 50ms stagger, 300ms par item |
| Bouton hover | `scale: 1.02` | 150ms easeOut |
| Bouton tap | `scale: 0.98` | 100ms easeIn |
| Modal entrée | `scaleIn` (0.95 → 1) + fadeIn | 200ms easeOut |
| Modal sortie | `scaleIn` exit (1 → 0.95) + fadeOut | 150ms easeIn |
| Toast | `slideRight` (x: 100 → 0) | 250ms easeOut |

Règles absolues:
- Pas de bounce (`cubic-bezier` avec valeur négative interdite dans cette phase)
- Pas de rotation 3D
- Pas d'animation sur scroll (ScrollReveal peut rester pour compatibilité tests, mais ne pas en ajouter)
- `will-change: transform` autorisé uniquement sur les modals (performance mobile)

> Source: user_decisions Q4 + animations.js existant + user_decisions (Framer Motion déjà en place)

## Accessibility Contract

- Contraste texte/fond minimum: 4.5:1 pour le texte courant (WCAG AA)
  - `#F9FAFB` sur `#111827`: ratio ~18:1 — conforme
  - `#9CA3AF` sur `#111827`: ratio ~5.7:1 — conforme
  - `#E05C3A` sur `#111827`: ratio ~3.2:1 — réservé accent uniquement (grands éléments), ne jamais utiliser pour du texte body
- Focus visible: `focus-visible:ring-2` obligatoire sur tous les éléments interactifs (boutons, liens, inputs)
- Touch targets: 44px minimum sur mobile (hauteur explicite ou padding compensatoire)
- `aria-label` sur les icônes standalone (sans texte adjacent)
- `data-testid` existants ne doivent pas être supprimés (305+ tests dépendent de ces attributs)

```js
// Borders dark

// Text dark
'text-primary': '#F9FAFB',   // gray-50 (était #1A1A1A)

'text-tertiary': '#6B7280',  // gray-500 (était #888888)
'text-disabled': '#4B5563',  // gray-600 (était #AAAAAA)
```

Les tokens corail (`primary`, `cta`, `cta-hover`, `cta-active`) sont conservés inchangés.
Les tokens sémantiques (`success`, `warning`, `error`, `info`) sont conservés inchangés.
