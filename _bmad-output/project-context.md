## 🏗️ Technology Stack & Versions
- **Core**: Node.js, TypeScript.
- **Backend**: Cloudflare Workers (Hono).
- **IA OCR**: Gemini 1.5 Flash, BMM (Bmad Method Model) Orchestrator.
- **Frontend**: PWA (Vanilla CSS / Aurora & Crystal Light themes).
- **Database**: Supabase / Neon Postgres.
- **Tools**: Docling (IBM), Bmad Method V6.

## ⚖️ Critical Implementation Rules
1. **Premium Aesthetic**: All UI must follow "Aurora" or "Crystal Light" guidelines. No placeholders.
2. **Offline-First**: Mobile scanner must work without connection.
3. **Data Sovereignty**: User chooses storage (R2, Google Drive, Dropbox).
4. **Idempotence**: Files are hashed before processing.
5. **Agentic UI**: Widgets generated dynamically via AI commands.

## 🛤️ Bmad Enterprise Track
This project follows the **Enterprise Track**, requiring:
- Full PRD / Architecture / Security / DevOps documentation.
- Test Architect (TEA) supervision.
- Semantic Design System (WDS).
