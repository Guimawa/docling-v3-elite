# EPIC-01: THE PULSER (MOBILE CAPTURE ENGINE)

## Summary
Implement the ultra-fast "Scan-and-Forget" mobile experience for document capture.

## User Stories
- **STORY-01-01**: As an artisan, I want a persistent camera session so I can scan invoices in <1s.
- **STORY-01-02**: As an artisan, I want auto-capture and perspective warping to avoid manual cropping.
- **STORY-01-03**: As an artisan, I want local image hashing to prevent duplicate uploads.
- **STORY-01-04**: As an artisan, I want real-time quality feedback (blur/low light) before the upload starts.
