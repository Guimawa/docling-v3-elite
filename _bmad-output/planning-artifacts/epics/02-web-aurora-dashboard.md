# EPIC-02: AURORA (WEB DASHBOARD)

## Summary
Implement the premium design dashboard with Glassmorphism and intelligent widgets.

## User Stories
- **STORY-02-01**: As an admin, I want to see my financial status through a high-contrast Aurora-themed UI.
- **STORY-02-02**: As an admin, I want to manage vital documents (Assurances, KBIS) in a "Vault" section.
- **STORY-02-03**: As an admin, I want to receive proactive notifications for document expiration.
- **STORY-02-04**: As an admin, I want agentic widgets that visualize my data on demand.
